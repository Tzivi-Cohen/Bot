Arduino – קלט אנלוגי, חיישנים ו־PWM
=====================================

הערה: הנתונים המספריים במסמך מתייחסים ל־Arduino UNO R3 (‏ATmega328P, ‏5V), לפי מסמכי ה־Language Reference הרשמיים של Arduino. בלוחות אחרים הרזולוציה, מתח העבודה, הפינים ותדרי ה־PWM שונים.

1. ממיר אנלוגי לדיגיטלי (ADC) ו־analogRead
-------------------------------------------
בלוח UNO יש שש כניסות אנלוגיות, A0 עד A5. הפונקציה analogRead(pin) מחזירה מספר שלם בין 0 ל־1023, כי הרזולוציה של ה־ADC היא 10 ביט (2^10 = 1024 רמות).
כשמתח הייחוס הוא 5V, כל יחידה שווה בערך 5V / 1024 ≈ 4.9mV.
המרה של קריאה למתח:

    int raw = analogRead(A0);
    float voltage = raw * (5.0 / 1023.0);

(יש מימושים שמחלקים ב־1024 ויש שמחלקים ב־1023. ההבדל זניח ברוב השימושים. החשוב הוא להשתמש באותה מוסכמה לאורך כל הפרויקט.)

קריאה אחת לוקחת כ־100 מיקרו־שניות, כלומר אפשר לבצע עד כ־10,000 קריאות בשנייה בלוחות מבוססי ATmega.
את טווח המדידה אפשר לשנות עם analogReference(). אסור להכניס לפין מתח שגבוה ממתח העבודה של הלוח.

2. פוטנציומטר ומחלק מתח
------------------------
פוטנציומטר הוא נגד משתנה עם שלוש רגליים. מחברים את הקצוות ל־5V ול־GND, ואת האמצעית (Wiper) לכניסה אנלוגית. זהו מחלק מתח (Voltage Divider), והמתח באמצע משתנה בין 0 ל־5V לפי מיקום הכפתור.

    void setup() {
      Serial.begin(9600);
    }

    void loop() {
      int raw = analogRead(A0);                  // 0..1023
      int percent = map(raw, 0, 1023, 0, 100);   // המרה לאחוזים
      Serial.println(percent);
      delay(200);
    }

הפונקציה map(value, fromLow, fromHigh, toLow, toHigh) ממפה ערך מטווח אחד לטווח אחר. היא עובדת עם מספרים שלמים (long), ולכן חותכת שברים.

3. חיישן אור (LDR) עם מחלק מתח
-------------------------------
נגד תלוי־אור (LDR, Photoresistor) משנה את התנגדותו לפי עוצמת האור. בדרך כלל התנגדותו יורדת כשיש יותר אור. בדרך כלל מחברים אותו במחלק מתח עם נגד קבוע, למשל 10kΩ:
5V — LDR — (A0) — 10kΩ — GND
המתח בנקודה A0 הוא Vout = 5V × R_fixed / (R_LDR + R_fixed). כשיש יותר אור, R_LDR קטן ו־Vout עולה.
ערכי ההתנגדות של LDR שונים מאוד בין דגמים. לכן קובעים את הסף בניסוי (כיול) ולא לפי נוסחה בלבד:

    const int THRESHOLD = 400;     // נקבע בניסוי
    void loop() {
      int light = analogRead(A0);
      digitalWrite(LED_BUILTIN, light < THRESHOLD ? HIGH : LOW);   // חושך – מדליקים
    }

4. חיישן טמפרטורה אנלוגי – דוגמה עם TMP36
-----------------------------------------
TMP36 הוא חיישן טמפרטורה שמוציא מתח ביחס ליניארי לטמפרטורה. לפי גיליון הנתונים של היצרן, היציאה היא 750mV ב־25°C, עם שיפוע של 10mV לכל מעלה. מכאן: T[°C] = (V - 0.5) × 100.

    void loop() {
      int raw = analogRead(A1);
      float v = raw * (5.0 / 1023.0);
      float tempC = (v - 0.5) * 100.0;
      Serial.println(tempC);
      delay(1000);
    }

חשוב: הנוסחה מתאימה ל־TMP36 בלבד. לחיישנים אחרים, כמו LM35 (שיפוע 10mV/°C בלי היסט של 0.5V) או NTC Thermistor (לא ליניארי), יש נוסחאות שונות. תמיד בודקים בגיליון הנתונים של החיישן.

5. PWM ו־analogWrite
---------------------
ב־UNO אין ממיר דיגיטלי לאנלוגי (DAC) אמיתי. analogWrite(pin, value) מייצרת אות PWM (Pulse Width Modulation): גל ריבועי שעובר כל הזמן בין 0V ל־5V. מחזור העבודה (Duty Cycle) – אחוז הזמן שבו האות ב־HIGH – קובע את המתח הממוצע.
- value הוא בין 0 (תמיד כבוי) ל־255 (תמיד דולק).
- analogWrite(pin, 64) נותן Duty Cycle של כ־25%, ומתח ממוצע של כ־1.25V.
- ב־UNO, ‏analogWrite עובדת רק על הפינים 3, 5, 6, 9, 10, 11 (מסומנים ב־~ על הלוח).
- תדר ה־PWM ב־UNO הוא כ־490Hz, חוץ מפינים 5 ו־6, שבהם הוא כ־980Hz.
- אין צורך לקרוא ל־pinMode(pin, OUTPUT) לפני analogWrite.
- לפי התיעוד הרשמי, בפינים 5 ו־6 ה־Duty Cycle בפועל גבוה מהצפוי, במיוחד בערכים נמוכים (בערך 0–10). הסיבה היא שהטיימר שלהם משמש גם את millis() ו־delay(). ייתכן שהערך 0 לא יכבה את היציאה לגמרי.

עמעום LED (Fade):

    const int LED_PWM_PIN = 9;

    void loop() {
      for (int b = 0; b <= 255; b++) {
        analogWrite(LED_PWM_PIN, b);
        delay(5);
      }
      for (int b = 255; b >= 0; b--) {
        analogWrite(LED_PWM_PIN, b);
        delay(5);
      }
    }

שליטה בבהירות LED לפי פוטנציומטר – שילוב של קלט אנלוגי ו־PWM:

    void loop() {
      int raw = analogRead(A0);          // 0..1023
      analogWrite(9, raw / 4);           // 0..255  (1024 / 4 = 256 רמות)
    }

6. PWM למנועים ולמנועי סרוו
----------------------------
- מנוע DC: מהירות המנוע נשלטת לפי ה־Duty Cycle. אסור לחבר מנוע ישירות לפין. הזרם גבוה מדי, ולמנוע יש השראות שיוצרת קוצי מתח. משתמשים בטרנזיסטור או MOSFET עם דיודת הגנה (Flyback Diode), או בדרייבר מנועים ייעודי (H-Bridge) לשליטה בכיוון.
- מנוע סרוו (Servo): נשלט בפולסים ברוחב משתנה שנשלחים בקצב קבוע, ולא ישירות ב־analogWrite. משתמשים בספרייה Servo.h:

    #include <Servo.h>
    Servo servo;
    void setup() { servo.attach(9); }
    void loop()  { servo.write(90); delay(1000); servo.write(0); delay(1000); }   // זווית במעלות

סרוו ומנועים צורכים זרם גבוה. מקובל להזין אותם ממקור מתח נפרד עם GND משותף ללוח.

7. החלקת קריאות רועשות (Moving Average)
----------------------------------------
קריאות אנלוגיות "קופצות" בגלל רעש. ממוצע נע מחליק אותן:

    const int N = 10;
    int samples[N];
    int idx = 0;
    long total = 0;

    int smoothRead(int pin) {
      total -= samples[idx];
      samples[idx] = analogRead(pin);
      total += samples[idx];
      idx = (idx + 1) % N;
      return total / N;
    }

(במשך N הקריאות הראשונות הממוצע נמוך מהאמת, כי המערך מתחיל באפסים.)

8. שאלות תרגול ופתרונות
------------------------
שאלה 1: analogRead(A0) מחזירה 512 בלוח UNO עם ייחוס של 5V. מה המתח בכניסה, בקירוב?
פתרון: כ־2.5V. החישוב: 512 × 5 / 1023 ≈ 2.50V.

שאלה 2: מה יהיה המתח הממוצע ביציאה אחרי analogWrite(9, 191), במקור של 5V?
פתרון: ה־Duty Cycle הוא 191/255 ≈ 75%, ולכן המתח הממוצע הוא כ־3.75V. ‏(אות ה־PWM עצמו עובר בין 0V ל־5V. רק הממוצע שלו הוא 3.75V.)

שאלה 3: למה analogWrite(7, 128) לא יעמעם נורה שמחוברת לפין 7 בלוח UNO?
פתרון: פין 7 אינו תומך ב־PWM ב־UNO. הפינים שתומכים הם 3, 5, 6, 9, 10, 11.

שאלה 4: חיישן TMP36 מוציא 0.72V. מה הטמפרטורה?
פתרון: (0.72 - 0.5) × 100 = 22°C.
