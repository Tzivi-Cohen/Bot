C – מצביעים ומערכים (Pointers and Arrays)
==========================================

1. מה זה מצביע (Pointer)?
--------------------------
כל משתנה בזיכרון נמצא בכתובת (Address). מצביע הוא משתנה שמכיל כתובת של משתנה אחר.
- האופרטור & מחזיר את הכתובת של משתנה (Address-of).
- האופרטור * לפני מצביע ניגש לערך שנמצא בכתובת (Dereference).

    #include <stdio.h>

    int main(void) {
        int x = 10;
        int *p = &x;          /* p מכיל את הכתובת של x */

        printf("%d\n", *p);   /* 10 – הערך בכתובת */
        *p = 25;              /* שינוי x דרך המצביע */
        printf("%d\n", x);    /* 25 */
        printf("%p\n", (void *)p);  /* הדפסת הכתובת עצמה */
        return 0;
    }

הטיפוס של המצביע (int *) קובע כמה בתים נקראים ב־Dereference, ואיך מתבצע חשבון מצביעים.

2. NULL ומצביעים לא מאותחלים
-----------------------------
מצביע שלא אותחל מכיל "זבל", כלומר כתובת אקראית. שימוש בו הוא Undefined Behavior (התנהגות לא מוגדרת): התוכנית עלולה לקרוס, או גרוע מזה – להמשיך לרוץ עם נתונים משובשים.
מקובל לאתחל מצביע ל־NULL ולבדוק אותו לפני שימוש:

    int *p = NULL;
    if (p != NULL) {
        *p = 5;
    }

Dereference של NULL הוא Undefined Behavior. במערכות הפעלה מודרניות הוא בדרך כלל גורם לקריסה (Segmentation Fault). במיקרו־בקרים בלי הגנת זיכרון, כתובת 0 עשויה להיות כתובת תקינה, ולכן השגיאה עלולה לא להתגלות מיד.

3. מערכים (Arrays)
-------------------
מערך הוא רצף של איברים מאותו טיפוס, ששמורים ברצף בזיכרון.

    int grades[5] = {90, 85, 77, 100, 68};
    grades[0] = 95;            /* אינדקס ראשון: 0 */
    /* grades[5] – מחוץ לגבולות! Undefined Behavior */

ב־C אין בדיקת גבולות (Bounds Checking). גישה מחוץ למערך עלולה לדרוס משתנים אחרים בזיכרון. זו אחת הסיבות הנפוצות לבאגים ולפרצות אבטחה (Buffer Overflow).

גודל מערך מחשבים עם sizeof:
    size_t n = sizeof(grades) / sizeof(grades[0]);   /* 5 */
החישוב הזה עובד רק במקום שבו המערך הוגדר, ולא בתוך פונקציה שקיבלה אותו כפרמטר (ראו סעיף 5).

4. הקשר בין מערכים למצביעים
----------------------------
ברוב הביטויים, שם של מערך "מתפרק" (Decays) למצביע לאיבר הראשון שלו. לכן arr[i] שקול ל־*(arr + i).

    int arr[4] = {10, 20, 30, 40};
    int *p = arr;          /* שקול ל־&arr[0] */
    printf("%d\n", *(p + 2));   /* 30 */
    printf("%d\n", p[3]);       /* 40 */

חשבון מצביעים (Pointer Arithmetic): p + 1 מתקדם בגודל של איבר אחד, ולא בבית אחד. אם p הוא int * ו־int תופס 4 בתים, אז p + 1 מתקדם 4 בתים בזיכרון.

ההבדלים בין מערך למצביע:
- sizeof(arr) מחזיר את גודל המערך כולו. sizeof(p) מחזיר את גודל המצביע (בדרך כלל 4 או 8 בתים, תלוי בארכיטקטורה).
- אי אפשר לבצע השמה לשם של מערך (arr = p; היא שגיאה). למצביע אפשר להציב כתובת אחרת.

5. העברת מערך לפונקציה
-----------------------
פונקציה מקבלת מצביע, ולא עותק של המערך. לכן חובה להעביר גם את האורך:

    double average(const int *values, size_t length) {
        if (length == 0) return 0.0;
        long sum = 0;
        for (size_t i = 0; i < length; i++) {
            sum += values[i];
        }
        return (double)sum / length;
    }

המילה const מבטיחה שהפונקציה לא תשנה את המערך. הקומפיילר יתריע אם תהיה כתיבה אליו.

6. מחרוזות ב־C
---------------
מחרוזת ב־C היא מערך של char שמסתיים בתו '\0' (Null Terminator).

    char name[6] = "Hello";   /* 5 תווים + '\0' = 6 */
    char *s = "Hi";           /* String Literal – אסור לשנות אותו! */

פונקציות מ־<string.h>:
- strlen(s) – אורך בלי '\0'.
- strcpy(dst, src) – העתקה. מסוכנת אם dst קטן מדי.
- strncpy, ועדיף snprintf(dst, size, "%s", src) – העתקה עם הגבלת גודל.
- strcmp(a, b) – השוואה. מחזירה 0 אם המחרוזות שוות. אסור להשוות מחרוזות עם ==, כי זה משווה כתובות.

7. מצביע למצביע ומערכים דו־ממדיים
----------------------------------
    int value = 7;
    int *p = &value;
    int **pp = &p;
    printf("%d\n", **pp);    /* 7 */

מערך דו־ממדי נשמר בזיכרון שורה אחרי שורה (Row-Major Order):
    int m[2][3] = {{1, 2, 3}, {4, 5, 6}};
    /* m[1][2] == 6, ובזיכרון: 1 2 3 4 5 6 */

8. העברה לפי מצביע (Pass by Pointer)
--------------------------------------
ב־C כל הפרמטרים מועברים לפי ערך (Pass by Value). כדי שפונקציה תשנה משתנה של הקורא, מעבירים את הכתובת שלו:

    void swap(int *a, int *b) {
        int tmp = *a;
        *a = *b;
        *b = tmp;
    }

    int x = 1, y = 2;
    swap(&x, &y);    /* x == 2, y == 1 */

9. שאלות תרגול ופתרונות
------------------------
שאלה 1: מה יודפס?
    int a[] = {5, 10, 15, 20};
    int *p = a + 1;
    printf("%d %d\n", *p, *(p + 2));
פתרון: 10 20. המצביע p מצביע על a[1], ו־p + 2 מצביע על a[3].

שאלה 2: למה הפונקציה הבאה לא מחזירה את גודל המערך?
    int count(int arr[]) { return sizeof(arr) / sizeof(arr[0]); }
פתרון: בתוך הפונקציה, arr הוא מצביע ולא מערך. sizeof(arr) מחזיר את גודל המצביע, ולכן התוצאה שגויה. יש להעביר את האורך כפרמטר נפרד.

שאלה 3: כתבו פונקציה שהופכת מערך של int במקום (In-Place).
פתרון:
    void reverse(int *arr, size_t n) {
        if (n < 2) return;
        size_t i = 0, j = n - 1;
        while (i < j) {
            int tmp = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
            i++;
            j--;
        }
    }

שאלה 4: מה הבעיה בקוד: char *s = "abc"; s[0] = 'X';
פתרון: s מצביע ל־String Literal. שינוי שלו הוא Undefined Behavior, ובמערכות רבות הוא שמור בזיכרון לקריאה בלבד. אם צריך מחרוזת שניתנת לשינוי, מגדירים מערך: char s[] = "abc";
