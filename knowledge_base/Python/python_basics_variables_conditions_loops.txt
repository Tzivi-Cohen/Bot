Python – יסודות: משתנים, טיפוסים, תנאים ולולאות
=====================================================

1. משתנים וטיפוסים (Variables and Types)
-----------------------------------------
ב־Python אין צורך להצהיר על טיפוס של משתנה. הטיפוס נקבע לפי הערך שמוצב בו, ומשתנה יכול לקבל בהמשך ערך מטיפוס אחר. גישה זו נקראת Dynamic Typing.

הטיפוסים הבסיסיים:
- int – מספר שלם בגודל לא מוגבל (מוגבל רק בזיכרון). לדוגמה: 42, -7, 10**30.
- float – מספר עשרוני (Floating Point) בדיוק כפול. לדוגמה: 3.14, 1e-3.
- bool – ערך אמת: True או False. bool הוא תת־מחלקה של int, ולכן True + True שווה 2.
- str – מחרוזת טקסט (Unicode). מחרוזות הן Immutable – אי אפשר לשנות תו בתוך מחרוזת קיימת.
- None – ערך מיוחד שמייצג "אין ערך".

    age = 25            # int
    price = 19.90       # float
    name = "Dana"       # str
    is_student = True   # bool
    result = None

    print(type(age))    # <class 'int'>

הפונקציה type() מחזירה את הטיפוס של ערך, והפונקציה isinstance(x, int) בודקת אם x הוא מופע של טיפוס מסוים.

המרת טיפוסים (Type Conversion):
    int("42")      # 42
    float("3.5")   # 3.5
    str(10)        # "10"
    int(3.9)       # 3  – החלק העשרוני נחתך, אין עיגול
    int("abc")     # ValueError

שימו לב לחלוקה:
- האופרטור / מחזיר תמיד float: 7 / 2 == 3.5
- האופרטור // הוא חלוקה עם עיגול כלפי מטה (Floor Division). טיפוס התוצאה תלוי באופרנדים:
  - כששני האופרנדים int, התוצאה int: 7 // 2 == 3, ו־-7 // 2 == -4. זה עיגול כלפי מטה, ולא חיתוך לכיוון אפס כמו int(-3.5) == -3.
  - אם אחד האופרנדים float, התוצאה float מעוגלת כלפי מטה: 7.0 // 2 == 3.0, ו־-7.5 // 2 == -4.0.
- האופרטור % מחזיר שארית: 7 % 2 == 1.
- האופרטור ** הוא חזקה: 2 ** 10 == 1024.

בעיית דיוק של float: 0.1 + 0.2 אינו שווה בדיוק ל־0.3, כי מספרים עשרוניים מיוצגים בבסיס 2. כדי להשוות מספרים עשרוניים משתמשים ב־math.isclose(a, b).

2. מחרוזות (Strings)
---------------------
    s = "Hello"
    s[0]          # 'H'  – אינדקס מתחיל ב־0
    s[-1]         # 'o'  – אינדקס שלילי סופר מהסוף
    s[1:4]        # 'ell' – Slicing: מההתחלה ועד (לא כולל) הסוף
    len(s)        # 5
    s.upper()     # 'HELLO'
    "ll" in s     # True

f-string היא הדרך המומלצת לשלב ערכים בתוך טקסט:
    name = "Noa"
    grade = 92.456
    print(f"{name} קיבלה {grade:.1f}")   # Noa קיבלה 92.5

3. תנאים (Conditions)
----------------------
מבנה if / elif / else. ב־Python ההזחה (Indentation) היא חלק מהתחביר – היא קובעת אילו שורות שייכות לבלוק.

    grade = 78
    if grade >= 90:
        print("מצוין")
    elif grade >= 70:
        print("טוב")
    else:
        print("נדרש שיפור")

אופרטורים לוגיים: and, or, not.
אופרטורי השוואה: ==, !=, <, >, <=, >=. אפשר לשרשר השוואות: 0 <= x < 10.

ערכים "שקריים" (Falsy): False, None, 0, 0.0, מחרוזת ריקה "", רשימה ריקה [], מילון ריק {}. כל שאר הערכים נחשבים "אמיתיים" (Truthy). לכן אפשר לכתוב:
    items = []
    if not items:
        print("הרשימה ריקה")

ההבדל בין == לבין is: האופרטור == משווה ערכים, והאופרטור is בודק אם שני שמות מצביעים על אותו אובייקט בזיכרון. להשוואה ל־None משתמשים ב־is: if x is None.

ביטוי תנאי בשורה אחת (Conditional Expression):
    status = "עבר" if grade >= 56 else "נכשל"

4. לולאות (Loops)
------------------
לולאת for עוברת על איברים של אובייקט שניתן לעבור עליו (Iterable): רשימה, מחרוזת, range ועוד.

    for i in range(5):        # 0, 1, 2, 3, 4
        print(i)

    for i in range(2, 10, 3): # 2, 5, 8 – התחלה, סוף (לא כולל), קפיצה
        print(i)

    fruits = ["תפוח", "בננה", "ענבים"]
    for index, fruit in enumerate(fruits):
        print(index, fruit)

לולאת while רצה כל עוד התנאי מתקיים:
    n = 10
    while n > 0:
        n -= 3
    print(n)   # -2

break יוצא מהלולאה מיד. continue מדלג לאיטרציה הבאה.
ללולאות ב־Python יש גם בלוק else, שרץ רק אם הלולאה הסתיימה בלי break:

    numbers = [3, 7, 11]
    for x in numbers:
        if x % 2 == 0:
            print("נמצא מספר זוגי")
            break
    else:
        print("אין מספר זוגי ברשימה")

5. רשימות ומילונים בקצרה
-------------------------
list היא רשימה סדורה שניתן לשנות (Mutable):
    nums = [5, 2, 9]
    nums.append(4)      # [5, 2, 9, 4]
    nums.sort()         # [2, 4, 5, 9]
    nums[0] = 100

dict הוא מילון של זוגות מפתח–ערך:
    student = {"name": "Dana", "grade": 88}
    student["grade"] = 91
    for key, value in student.items():
        print(key, value)
    student.get("age", 0)   # מחזיר 0 אם המפתח לא קיים, בלי KeyError

List Comprehension – בניית רשימה בשורה אחת:
    squares = [x * x for x in range(6)]            # [0, 1, 4, 9, 16, 25]
    evens = [x for x in range(20) if x % 2 == 0]

6. טעויות נפוצות
-----------------
- הזחה לא עקבית (ערבוב Tab ורווחים) גורמת ל־IndentationError.
- input() מחזיר תמיד str. כדי לחשב יש להמיר: age = int(input("גיל: ")).
- שינוי רשימה בזמן שעוברים עליה בלולאת for עלול לדלג על איברים. עדיף לבנות רשימה חדשה.
- שימוש ב־= (השמה) במקום == (השוואה) בתוך תנאי הוא שגיאת תחביר ב־Python.

7. שאלות תרגול ופתרונות
------------------------
שאלה 1: מה יודפס?
    print(17 // 5, 17 % 5, -17 // 5)
פתרון: 3 2 -4. החלוקה השלמה מעגלת כלפי מטה, ולכן -17 // 5 הוא -4 (ולא -3).

שאלה 2: כתבו לולאה שסוכמת את כל המספרים בין 1 ל־100 שמתחלקים ב־3 או ב־5.
פתרון:
    total = 0
    for n in range(1, 101):
        if n % 3 == 0 or n % 5 == 0:
            total += n
    print(total)   # 2418
או בשורה אחת: sum(n for n in range(1, 101) if n % 3 == 0 or n % 5 == 0)

שאלה 3: מה ההבדל בין break ל־continue?
פתרון: break מסיים את הלולאה כולה. continue מסיים רק את האיטרציה הנוכחית וממשיך לבאה.

שאלה 4: כתבו קוד שמקבל מחרוזת ומדפיס כמה תנועות (a, e, i, o, u) יש בה באנגלית.
פתרון:
    text = "Embedded Systems"
    count = sum(1 for ch in text.lower() if ch in "aeiou")
    print(count)   # 4  (e, e, e ב־Embedded ו־e ב־Systems; y אינה בין התנועות שנבדקו)
